## Problem Statement

A comprehensive analysis of the global population has been developed in Power BI, offering an insightful visualization of demographic distribution by area. The first page of the dashboard presents an overview by continent and country, featuring an interactive map with color-coded circles. The size of each circle represents population concentration in a specific region: the larger the circle, the higher the population density in that area. This visualization helps identify the most densely populated regions and provides a clear understanding of population distribution patterns worldwide.

The second page shifts the focus to key global indicators, analyzing infant mortality rates and life expectancy across regions. Life expectancy is measured in average years, while infant mortality is expressed as the number of deaths per 1,000 live births. These indicators offer valuable insights into public health conditions, socioeconomic development, and quality of life across different countries and continents. By comparing these metrics, the dashboard enables users to explore global disparities, recognize patterns, and make data-driven decisions to address demographic challenges and improve living conditions worldwide.
